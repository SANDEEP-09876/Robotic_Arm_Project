# Wheel Driver Connections

| NodeMCU | Motor Driver |
|----------|--------------|
| D5 | Left IN1 |
| D6 | Left IN2 |
| D7 | Right IN1 |
| D8 | Right IN2 |
| GND | GND |

# Power Connections

| Power Supply | Driver |
|---------------|--------|
| +12V / +5V | VIN |
| GND | GND |

# Motor Connections

| Driver Output | Motor |
|----------------|-------|
| OUT1 & OUT2 | Left Wheels |
| OUT3 & OUT4 | Right Wheels |
